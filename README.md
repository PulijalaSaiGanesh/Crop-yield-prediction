It is a Hackathon project we made which predicts the Crop Yield for the given Xl Data of Crops 
xl data consists of crops and its specifications like year, rainfall, Fertilizers, Area and many other factors involving
Firstly the machine learning AI learns the yield data prediction from the previous yeild given and then it generates the approximate yield that can be produced when the present information about the crops is given.
More the sample Crop yield data more will be the prediction of the AI for the given data.
By running the test.py and inserting the crop yeild xl data it can produce the predicted data.
